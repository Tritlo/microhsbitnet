A 2B BitNet, in a browser tab, in Haskell.

The model math is Haskell. A small compiler turns that Haskell into a GPU kernel. The loop that feeds the kernel is Haskell too, compiled by MicroHs to C and then to WebAssembly. The page only supplies WebGPU.

Weights stream from Hugging Face (about 1.18 GB). The first tokens arrive after the upload. This page does not run without WebGPU, and it does not pretend a missing GPU is a pass.
