A 2B BitNet, in a browser tab, in Haskell.

The model math is Haskell. A small compiler turns that Haskell into a GPU kernel. The loop that feeds the kernel is Haskell too, compiled by MicroHs to C and then to WebAssembly. The page only supplies WebGPU.

Starting downloads 1.18 GB of model weights (1,178,623,988 bytes), plus the tokenizer, from Hugging Face. A physical WebGPU adapter and several GB of available memory are required. Tested on Apple M4 with Chrome 156.

Research demo: the six-prompt reference check matched 52/52 tokens, but its 1% numerical error target still fails. This page runs five fixed prompts.
